# BERGSTIEG

Кинематографичный подъём на вершину, где каждое упражнение по немецкому
становится выбором выживания. Камни срываются с гребня, лавины сносят
обратно к подножию, метель налипает на камеру, а склон к финалу сессии
превращается из снежной стены в раскалённую вулканическую трещину.

## Как это работает

1. **Подготовка (3 шага)**
   - Имя альпиниста и уровень CEFR (A1–C1).
   - Одна лексическая тема на всю сессию.
   - Пять грамматических тем — каждая закрепляется за своей бонусной кнопкой.
2. **Подъём**
   - Камера стоит за плечом альпиниста. Высота растёт, фаза горы меняется.
   - На склоне появляются камни (по линиям) и лавины (по всей ширине).
   - Нажатие бонусной темы открывает упражнение. Правильный ответ запускает
     привязанный бонус: +2 хода вверх, рывок на линию, сильный рывок на две
     линии, снежный щит, очистка камеры.
   - Пока вы отвечаете, опасности продолжают приближаться.
3. **Финал**
   - Вершина: экран победы с точностью, количеством правильных ответов и
     временем подъёма.
   - Падение: камень сбил с троса — экран поражения с разбором.

## Управление

| Действие | Клавиатура | Касание |
| --- | --- | --- |
| Открыть тему 1–5 | `1` … `5` | Кнопки справа внизу |
| Ответить 1–4 | `1` … `4` | Варианты в карточке вопроса |
| Сместиться на линию | `A` / `D` или `←` / `→` | Тап по левому / правому краю экрана |
| Пауза | `Esc` | Кнопка «Пауза» в правом верхнем углу |
| Звук | `M` | Кнопка «Звук» в правом верхнем углу |
| Выйти к настройке | — | Кнопка «Выход» в правом верхнем углу |

Состояние игры (имя, уровень, лексическая тема, распределение по слотам,
mute) сохраняется в `localStorage` и подхватывается между сессиями.

## Запуск

Требуется Node.js ≥ 18 (чистая стандартная библиотека, без внешних
зависимостей).

```bash
npm start         # http://127.0.0.1:3000
PORT=4000 npm start
```

Health-check для платформ деплоя: `GET /healthz`.

## Стек

- **Рендер.** three.js r128 (CDN), `PlaneGeometry` с вертексным смещением для
  склона, общий helper `_mountainProfile`, который использует и меш-билдер,
  и система расстановки пропсов (камни, вмятины, трещины). Это держит
  геометрию и реквизит синхронными — валуны не «плавают» над склоном.
- **Свет.** `HemisphereLight` + направленный солнечный свет с
  `PCFSoftShadowMap`, `ACESFilmicToneMapping`, `sRGBEncoding`,
  кастомный шейдерный sky-dome.
- **Звук.** Web Audio API: ветер на полосовом шуме, лоу-драён на треугольной
  волне, транзиенты через осцилляторы + огибающие. Master-gain и suspend
  используются для mute и паузы.
- **Сервер.** Чистый `node:http` (`server.js`): строгий 404 для JS/CSS/картинок,
  SPA-fallback для остальных путей, заголовки кэширования, graceful shutdown
  на SIGTERM/SIGINT.

## Структура

```
.
├── server.js              # Статический сервер + SPA fallback + /healthz
├── package.json           # Без зависимостей, только скрипты start / dev
├── render.yaml            # Конфиг деплоя на Render
└── public/
    ├── index.html         # Меню + игровой HUD + оверлей паузы
    ├── css/style.css      # Кинематографичная тёмная тема + адаптив
    └── js/
        ├── audio.js       # AudioManager (ветер, дрон, транзиенты, mute)
        ├── questions.js   # Уровни, лексические/грамматические темы, банк вопросов
        ├── renderer.js    # Сцена three.js, гора, опасности, камера за плечом
        ├── game.js        # Игровой цикл, физика линий, бонусы, пауза, тач-управление
        └── main.js        # Меню подготовки и склейка состояний
```

## Разработка

- Никаких сборщиков: правьте файлы в `public/` — сервер отдаёт их как есть.
- Линт/тесты в репозитории не заведены; проверка синтаксиса — `node --check`.
- Клавиатурные хоткеи задаются в `game.js._bindUi`, HUD-кнопки — в `index.html`
  и подключаются там же.

## Лицензия

Проприетарный прототип. Не распространять без письменного разрешения авторов.
